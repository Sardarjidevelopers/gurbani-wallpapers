# Hyperframes Composition Brief: Gurbani Wallpapers

## Objective
Create a short, quiet launch-style video for Gurbani Wallpapers.

## Output
- Composition directory: `brag-output/composition/`
- Rendered video: `brag-output/brag.mp4`
- Format: vertical, 1080x1920
- Duration: about 23.6 seconds

## Source Material
- Project root: /home/user/gurbani-wallpapers
- Primary files read: store/LISTING.md, README.md, the app's real screenshots and exported wallpapers
- Product name: Gurbani Wallpapers
